# AWS Activate Credits – Step-by-Step Guide

**Purpose:** Apply for AWS Activate credits for CyberCyko Technologies Private Limited using the existing AWS account.

---

## 1. Basic Information

- **Company:** CyberCyko Technologies Private Limited
- **CIN:** U62090AP2025PTC121634
- **Website:** cybercyko.com
- **AWS Account ID:** 235473625258
- **Preferred Route:** AWS Activate Portfolio through Startup India / DPIIT
- **Fallback Route:** AWS Activate Founders, if the Portfolio route cannot be completed

---

## 2. What is AWS Activate?

AWS Activate is a program that provides eligible startups with AWS promotional credits. These credits can reduce the cost of eligible AWS services.

Startup India currently lists an AWS Activate benefit of **$5,000** for eligible DPIIT-recognized startups.

---

## 3. Portfolio and Founders Routes

### Portfolio
Uses an AWS Activate Provider and requires an Org ID. This is the preferred route for this task.

### Founders
A self-service route for eligible startups. Use it as a fallback after checking the current AWS eligibility requirements.

> **Important:** Do not create a new AWS account. The credits should be linked to AWS account **235473625258**.

---

## 4. Step 1 – Check the AWS Account

- Log in to the AWS Management Console using the authorized company access.
- Confirm that the account ID is **235473625258**.
- Do not continue if a different AWS account is shown.
- Check whether the account has previously applied for or received AWS Activate credits.

---

## 5. Step 2 – Request the Startup India Org ID

- Open the Startup India AWS benefit page.
- Find the AWS Activate benefit and follow the request/application process.
- Request the AWS Activate Organizational ID (Org ID).
- Record the request date and any reference number on the ticket.

> **Note:** The Org ID is different from the DPIIT number and AWS Account ID. Do not guess or share the Org ID publicly.

---

## 6. Step 3 – Prepare the Application

Keep the following information ready before starting the AWS Activate application:

- Company name and website
- Founder details and business contact information
- DPIIT recognition certificate
- Company incorporation details
- AWS Account ID: **235473625258**
- Startup India / DPIIT Org ID
- Approved company/product description
- State clearly that Windows is the production platform, if required by the application

---

## 7. Step 4 – Apply Through AWS Activate

- Open the AWS Activate credits page and sign in with the required AWS identity.
- Choose the **Portfolio** route.
- Enter the Org ID received from Startup India.
- Link the existing AWS account **235473625258**.
- Review all information carefully before submitting.
- Do not enter passwords, secret keys, MFA codes, or other confidential credentials in the application.

---

## 8. Step 5 – Record the Submission

- Record the submission date.
- Record the AWS application/reference number.
- Record the route used: **Portfolio**.
- Update the project ticket with the current status.

---

## 9. Step 6 – Wait for the Decision

Monitor the email address used for the application and the AWS Activate account.

AWS currently states that applications generally receive a response within **5–10 business days**.

If the Startup India Org ID is not received within the internal two-week follow-up period, check the current AWS eligibility rules before using the Founders route.

---

## 10. Step 7 – Verify the Credits

- After approval, open **AWS Billing and Cost Management**.
- Open the **Credits** section.
- Confirm that the credits are attached to AWS account **235473625258**.
- Record the credit amount, start date, expiry date, and eligible services/products.
- Check the credit terms for exclusions such as Marketplace services.

---

## 11. Step 8 – Update the Ticket

The ticket should contain:

- Application route
- Submission date
- Application/reference number
- Credit amount granted
- Credit start date
- Credit expiry date
- Eligible services/coverage
- AWS Billing verification date
- Current status

---

## 12. Step 9 – Monitor the Credits

- Set a calendar reminder for the credit expiry date.
- Check the remaining credit balance every month.
- Compare remaining credits with expected AWS usage.
- Monitor the credits before the expiry date so unused credits are not overlooked.

---

## 13. Definition of Done

- [ ] Org ID requested and received
- [ ] Correct existing AWS account used
- [ ] AWS Activate application submitted
- [ ] Application decision received
- [ ] Credits visible in AWS Billing
- [ ] Credit amount, expiry date, and coverage recorded
- [ ] Expiry and monthly monitoring reminders created

---

## Important Points

- Never create a new AWS account for this application.
- Never guess the Startup India Org ID.
- Verify every application field before submitting.
- Do not share AWS passwords, access keys, secret keys, or MFA codes.
- Use the actual credit terms shown by AWS when recording service coverage.
